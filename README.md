# TFI — the Telugu Film Industry party game

A pass-the-phone party game for Telugu movie fans, built as a native iOS and Android app with **Expo SDK 57 + React Native + TypeScript**.

Open TFI → pick a game → hand the phone to your friends → play.

- **Three games:** 🎬 Movie on My Head · 🔗 What's Common? · ⏳ Before or After?
- **Text only:** no posters, stills, audio or video.
- **Offline:** all content ships in the app. No backend, no sign-in, no AI calls, no personal data stored.

## Running it

```bash
npm install
npx expo start          # scan with Expo Go, or press i / a for a simulator
```

For a real feel check (tilt sensitivity, haptics, 120 Hz animation), use a release build on a device:

```bash
npx expo run:ios --configuration Release
npx expo run:android --variant release
# or in the cloud: npx eas-cli@latest build --profile preview
```

`ios/` and `android/` are generated by `expo prebuild` and are git-ignored. Configure native behaviour in `app.json`.

## Adding content

Content is plain typed data, so new packs need no changes to game logic. Append to the matching file in `src/data/` with a new unique `id`:

```ts
// movieOnMyHead.ts
{ id: 'mmh-031', title: 'New Movie' },

// whatsCommon.ts
{ id: 'wc-031', clues: ['Clue 1', 'Clue 2', 'Clue 3'], answer: 'The connection' },

// beforeOrAfter.ts — `correct` names the one released first
{ id: 'boa-031', a: { title: 'Older', year: 2001 }, b: { title: 'Newer', year: 2002 }, correct: 'a' },
```

`npm test` runs `validateContent` to catch duplicate ids, missing clues, empty answers, and a `correct` movie with a later year. In development the app also logs a warning on launch if content fails validation. Before or After shuffles which movie appears on top, so the order you write `a`/`b` in never gives the answer away.

## How the games work

**Movie on My Head** is played in landscape. The phone counts down once it sits upright on someone's forehead. Tilt **down** (screen to the floor) for Correct (+1) and tilt **up** for Skip. The tilt detector needs a clear threshold (40° from the calibrated start position) held for consecutive samples, then a return to neutral and a cooldown before it can fire again, so one nod can never score twice. If motion is unavailable or denied, or you pick **Buttons** on the How to Play screen, large Correct and Skip buttons appear instead. Rounds are 30, 60 or 90 seconds (60 by default), with no repeated cards in a round.

**What's Common?** plays 5, 10 or 15 rounds (10 by default) picked at random without repeats. The answer stays hidden until the Reader taps SHOW ANSWER. Only then can the card be swiped (right for Correct, left for Wrong) or scored with the buttons.

**Before or After?** also plays 5, 10 or 15 matchups (10 by default). Years stay hidden. The Reader can hold PEEK to check the answer privately, then swipes or taps to record the result. The correct movie and both years are shown after scoring.

All active rounds keep the screen awake. They pause while the leave dialog is open, and the timed game also pauses while the app is in the background. Haptics always come with a visual cue.

## Device QA checklist

Code-level tests cover the engine. These states still need a physical device:

- [ ] Fresh launch → Home renders with fonts, no flash of white
- [ ] Movie on My Head: auto-countdown when the phone is upright on a forehead
- [ ] Tilt down = Correct, tilt up = Skip feels natural, and does not trigger from talking or laughing
- [ ] Rapid nodding scores one card per nod, never two
- [ ] Motion permission denied (iOS Settings → TFI → Motion & Fitness off) → buttons appear
- [ ] Timer reaches 0 → TIME! → results in portrait
- [ ] Swipe short of the threshold springs back; a flick commits
- [ ] Exit button, Android back and iOS swipe-back all ask "Leave this round?"
- [ ] Play again and Home from results
- [ ] Small phone (iPhone SE / 360dp Android) and large phone (Pro Max)
- [ ] Reduce Motion on: no confetti or marquee chase, transitions still clear
